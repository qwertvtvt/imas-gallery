# IM@S Gallery

アイドルマスターシリーズの画像を投稿・閲覧できる、非公式のファン向けギャラリーサービスです。

## About

IM@S Galleryは、アイドルマスターシリーズに関連する画像をユーザーが投稿・閲覧できるWebサービスです。

本プロジェクトは、Kikuflare氏が開発した「imas765probot」の構想を起点として発展したものです。

既存プロジェクトのコードを引き継ぐものではなく、その構想を参考に、アイドルマスターシリーズ全体を対象とした独立したサービスとして新たに開発しています。

ブランドやアイドルごとの画像閲覧、タグによる分類・検索などを通じて、ファンが作品を共有し、楽しめる場所を目指します。

## Features

- アイドルマスターシリーズ全体に対応
- ブランド・アイドル別の画像閲覧
- 画像の投稿・審査・公開
- タグによる画像の分類・検索
- ユーザープロフィール
- ユーザーアカウント管理
- Xアカウント連携
- 公式Xアカウントへの投稿連携（対象投稿のみ）

## Image Submission Policy

投稿できる画像は、**自分が制作・撮影した画像、または権利者から投稿・掲載の許可を得た画像のみ**とします。

他者が制作した画像の無断転載や、権利関係が確認できない画像の投稿は禁止します。

投稿された画像は、公開前に審査を行います。

また、Webサイトへの掲載許可と、公式Xアカウントへの掲載許可は別々に扱います。Web掲載が認められた画像であっても、公式Xへの投稿が認められるとは限りません。

投稿者には、画像の出所や権利関係について正確な情報を申告してもらいます。

## Account System

IM@S Gallery独自のアカウントを使用します。

- ユーザー名とパスワードによるログイン
- メールアドレスの登録は必須としない
- パスワードを忘れた場合は、登録時に発行されるリカバリーコードで復旧
- Xアカウント連携は任意

Xアカウントを連携しなくても、通常の投稿・閲覧機能を利用できます。

## Moderation

すべての画像投稿は、公開前に審査を受ける必要があります。

初期段階では管理者が審査を担当し、将来的には審査員を複数人に増やせる構成を想定しています。

ユーザーには通常利用者・審査員・管理者の権限を設けます。

## Official X Account

公式Xアカウントとの連携を予定しています。

公式Xへの自動投稿は、Xアカウントを連携済みで、かつ公式Xへの掲載に必要な条件を満たした投稿のみを対象とします。

X連携はIM@S Galleryの利用に必須ではありません。

## Project Structure

本プロジェクトでは、フロントエンドとバックエンドを同一リポジトリで管理するモノレポ構成を採用しています。

```text
imas-gallery/
├── frontend/
├── backend/
├── docs/
├── .github/
├── .gitignore
├── .env.example
└── README.md
```

フロントエンドとバックエンドはそれぞれ独立した `package.json` を持ちます。

## Deployment

開発環境と本番環境では、プログラムの配置先を分離します。

| Purpose | Path |
|---|---|
| Development Program | `~/projects/imas-gallery` |
| Production Program | `/opt/imas-gallery` |
| Persistent Data | `/srv/imas-gallery` |

画像・データベースなどの永続データは `/srv/imas-gallery` 以下で管理します。

本番運用時には、専用USB SSDを同じパスにマウントする予定です。開発環境と本番環境のデータは論理的に分離します。

## Development Policy

- 新規リポジトリ・新規コードで開発する
- Gitによるバージョン管理を行う
- フロントエンドとバックエンドはREST APIで通信する
- データベースへのアクセスはバックエンド経由とする
- 秘密情報や環境変数をGitリポジトリに含めない
- 投稿画像は公開前に審査する

## Backup Policy

初期運用では、予算上の制約から定期バックアップ用の別ストレージは用意しません。

ストレージ障害などによるデータ消失の可能性があります。今後、利用状況や運用規模に応じてバックアップ体制を再検討します。

## Project Status

現在は基本設計を終え、詳細設計・実装に向けた準備を進めています。

今後の開発では、データベース設計、API設計、認証・投稿機能などの実装を順次進める予定です。
